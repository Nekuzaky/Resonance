# Security Policy

Resonance makes no network request and writes nothing outside the project. In players it only reads the Resonance
assets your game references and plays them through Unity's own audio.

## Reporting a vulnerability

Please **do not** open a public issue for security problems. Use GitHub's private
[security advisory form](https://github.com/Nekuzaky/Resonance/security/advisories/new) instead, with steps to
reproduce. You should get an answer within a few days.

## Supported versions

Only the latest release receives fixes.
