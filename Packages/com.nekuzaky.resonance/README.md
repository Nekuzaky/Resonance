# Resonance

Game audio middleware that lives inside Unity: sound events built from containers, parameters, switches and states,
buses with effects, ducking and snapshots, voice management, interactive music and a live profiler, all authored in the
**Resonance Studio** window. No soundbanks, no external tool, no code required.

- Open the Studio: **Tools > Resonance > Resonance Studio** (`Ctrl+Alt+R`)
- Documentation: [Documentation~/index.md](Documentation~/index.md)
